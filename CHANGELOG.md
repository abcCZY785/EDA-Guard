# Changelog

All notable changes to EDA-Guard are recorded here.

## 0.1.0-alpha.1 — 2026-09-14

- Added the public Alpha release candidate structure and offline demo.
- Capture foundation: deterministic, fail-closed canonical snapshots for the Basic Snapshot Profile.
- Basic Semantic Diff: explain component, property, BOM, connectivity, geometry, rule, layer, and routing changes.
- Intent Lock: compile a baseline-bound default-deny policy and verify a diff.
- Hardware Assertions: compile and run deterministic component, BOM, connectivity, geometry, and count checks.
- Added Apache-2.0 licensing, security/contribution guidance, roadmap, CI, and release audits.

Known limitations are documented in [README.md](README.md) and the capability matrix.
