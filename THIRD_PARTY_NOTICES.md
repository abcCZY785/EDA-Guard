# Third-party notices

The Alpha CLI has no runtime npm dependencies. It uses Node.js built-ins only
(`node:crypto`, `node:fs`, `node:path`, `node:test`, and related standard
modules). Node.js is distributed under its own license.

The EasyEDA API skill and official Bridge are development-time integration
surfaces. They are not bundled into this package and no EasyEDA code is
redistributed here.
